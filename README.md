# 骸王の行軍 (overload-td)

ダークファンタジーのドット絵タワーディフェンス。Godot 4 で作った個人用のゲームです。
冥王ザルヴァスの亡者軍を率いて、白銀教団の砦を落とします。キャラクター・名称・ドット絵はすべてオリジナルです。

## 遊び方（すぐ起動する）

### Windows

1. [Godot 4.3 以降](https://godotengine.org/download/windows/) の通常版（.NET版ではない方）のzipをダウンロード
2. zipをこのフォルダの `tools` フォルダに展開する（または「ダウンロード」フォルダに置いたままでもOK）
3. `run_game.bat` をダブルクリック

`run_game.bat` はGodotを自動で探します（`tools`、ダウンロード、デスクトップ、Program Files、PATH、scoop、Steam）。見つからないときはダウンロードページを開き、exeのパスを聞いてきます。一度見つけたパスは `.godot_path` に保存されます。ログやエラーはこの黒いウィンドウに表示されます。

| コマンド | 内容 |
|---|---|
| `run_game.bat` | 通常起動 |
| `run_game.bat 10` | デバッグモードで、いきなりステージ10のバトルから開始 |
| `run_game.bat debug` | デバッグモードで起動（拠点から） |
| `run_game.bat edit` | Godotエディタでプロジェクトを開く |

### macOS / Linux

`./run_game.sh`（引数は `.bat` と同じ）。Godotは `$GODOT`、PATHの `godot`、`/Applications/Godot.app` の順で探します。

## デバッグ機能

デバッグモード（`run_game.bat 10` / `debug`、またはGodotエディタからF5で実行）では：

- **F1** でデバッグパネルを開閉：魂貨・冥核の付与、全カード入手・Lv上げ、パッシブ全開放／リセット、任意ステージへ出撃、バトル中の即勝利・即敗北・魂力満タン・待ち時間0・裁きチャージ・×4速
- 通常とは**別のセーブ**（`user://necrothrone_save_debug.json`）を使うので、普段のデータは壊れません
- 起動オプション（Godotに直接渡す場合は `--` の後ろに書く）：`--debug`、`--stage=N`、`--fresh`（デバッグ用セーブを初期化）

例：`Godot_v4.3-stable_win64_console.exe --path . -- --stage=5 --fresh`

## ゲームの流れ

1. **出撃（タワーディフェンス）**：左の「骨の玉座」から亡者を召喚し、右の「白銀の砦」を壊せば勝利。玉座が壊されるか3分経過で敗北。1戦は30秒〜3分。
2. **戦利品（ローグライト）**：勝利ごとに「新カード／カード強化／遺物／遺物の欠片」から1つ選ぶ。
3. **強化シーン**：魂貨でカードのレベルと玉座（魂力回復・上限・耐久・魂貨倍率）を強化。デッキは最大6枚。
4. **転生とパッシブスキル**：行き詰まったらステージ・カード・玉座の強化を捨てて冥核を得る（遺物と欠片は残る）（今周の最高ステージ5以上で解放）。ボスの初撃破でも冥核+2。冥核で「パッシブスキル」を解放・強化し、突破できなかったステージに再挑戦する。

### 遺物（インフレの軸）

遺物は**一度見つけたら転生しても残る**永続コレクションです。バトルで手に入る「遺物の欠片」でLvを上げます。

- **入手**：ボスの初撃破で1つ確定、勝利時の戦利品でも出る（所持済みならLv+1）
- **欠片**：勝つと満額、負けても少し。ステージが進むほど指数的に増える（`3 × 1.14^(ステージ-1)`）
- **効果**：「×」型はLvごとに掛け算で伸びる（例：呪われた冠 ×1.2^Lv）。「+」型は足し算で上限あり
- **レア度**：普通／希少／伝説（伝説ほど出にくく強化コストも高い）。全14種

| レア度 | 遺物 |
|---|---|
| 普通 | 呪われた冠（攻撃×）・死皮の外套（体力×）・墓守の財布（魂貨×）・骨の大盾（玉座×）・葬送の鐘（裁き×） |
| 希少 | 黒血の聖杯（魂力回復+）・亡者の行進曲（移動+）・黒砂の時計（CD短縮）・屍眼の水晶（会心率）・血牙の首飾り（欠片×）・魂喰らい（撃破で魂力） |
| 伝説 | 冥王の心臓（攻撃と体力×）・禁書「終末の頁」（冥核+）・共鳴の鎖（所持遺物数に応じて攻撃×） |

敵も `1.13^ステージ` で強くなるので、遺物の倍率を伸ばし続けることで数値がどんどんインフレしていきます。大きな数は `12.3K → 4.56M → 7.89B → 1.23T → … → 1.20Dc`、それ以上は `9.87e45` のように表示します。

**3つの成長の関係**：遺物（欠片で強化・永続・数値の伸び）／パッシブスキル（冥核で解放・永続・新しい戦い方）／カードと玉座の強化（魂貨・転生でリセット）。

### パッシブスキル

3系統×3段階のスキルツリー。前の段階のスキルを育てると次が解放される（転生しても失われない）。

| 系統 | 第1段階 | 第2段階 | 第3段階 |
|---|---|---|---|
| 軍勢の業 | 冥王の威光（攻撃）・不死の肉体（体力） | 骨の再生（自動回復）・魂吸い（吸収） | 不死の執念（致命傷を1度耐える）・死者の行進（骸骨兵を自動召喚） |
| 玉座の業 | 冥府の蓄え（開始魂力）・冥河の流れ（魂力回復） | 玉座の呪砲（自動砲撃）・瘴気の結界（敵を減速） | 黒き儀式（クールダウン短縮）・骨の城塞（玉座強化） |
| 冥術の業 | 魂の収穫（魂貨）・冥王の怒り（必殺技威力） | 速唱（必殺技チャージ短縮）・弱体の呪詛（敵の攻撃力低下） | 終焉の刻（必殺技で吹き飛ばし＋砦に直撃）・古の盟約（転生時に追加カード） |

## 操作

- カードをクリック／タップ、またはキー `1`〜`6` で召喚
- `Space` / `Q`：冥王の裁き（全敵へ範囲攻撃、チャージ制）
- ×1 / ×2：戦闘速度の切り替え
