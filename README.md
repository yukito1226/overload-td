# 骸王の行軍 (overload-td)

ダークファンタジーのドット絵タワーディフェンス。ブラウザだけで動く個人用のWebゲームです。
冥王ザルヴァスの亡者軍を率いて、白銀教団の砦を落とします。キャラクター・名称・ドット絵はすべてオリジナルです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。進行状況はブラウザの localStorage に保存されます。

## ゲームの流れ

1. **出撃（タワーディフェンス）**：左の「骨の玉座」から亡者を召喚し、右の「白銀の砦」を壊せば勝利。玉座が壊されるか3分経過で敗北。1戦は30秒〜3分。
2. **戦利品（ローグライト）**：勝利ごとに「新カード／カード強化／遺物」から1つ選ぶ。
3. **強化シーン**：魂貨でカードのレベルと玉座（魂力回復・上限・耐久・魂貨倍率）を強化。デッキは最大6枚。
4. **放置収穫**：離れている間も魂貨が溜まる（最大8時間）。
5. **転生**：行き詰まったらステージ・カード・強化・遺物を捨てて冥核を得る（今周の最高ステージ6以上で解放）。冥核で「冥王の遺志」（永続強化）を取得。

## 操作

- カードをクリック／タップ、またはキー `1`〜`6` で召喚
- `Space` / `Q`：冥王の裁き（全敵へ範囲攻撃、チャージ制）
- ×1 / ×2：戦闘速度の切り替え
