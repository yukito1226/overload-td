# 骸王の行軍 (overload-td)

ダークファンタジーのドット絵タワーディフェンス。Godot 4 で作った個人用のゲームです。
冥王ザルヴァスの亡者軍を率いて、白銀教団の砦を落とします。キャラクター・名称・ドット絵はすべてオリジナルです。

## 遊び方

1. [Godot 4.3 以降](https://godotengine.org/download/) をインストール
2. Godot のプロジェクトマネージャーで「インポート」→ このフォルダの `project.godot` を選択
3. F5（再生ボタン）で起動

進行状況は `user://necrothrone_save.json` に保存されます。

## 構成

| ファイル | 役割 |
|---|---|
| `project.godot` | プロジェクト設定（960×620、ピクセル表示、自動ロード） |
| `scenes/main.tscn` / `scripts/main.gd` | 拠点⇄バトルの画面遷移とダイアログ |
| `scripts/data.gd` | ドット絵（文字列のピクセルマップから実行時にテクスチャ生成）、カード・敵・遺物・強化のデータ |
| `scripts/game.gd` | セーブデータと各種計算式、UIテーマ |
| `scripts/hub.gd` | 拠点画面（カード編成・強化・転生） |
| `scripts/battle.gd` | タワーディフェンスのバトル |

## ゲームの流れ

1. **出撃（タワーディフェンス）**：左の「骨の玉座」から亡者を召喚し、右の「白銀の砦」を壊せば勝利。玉座が壊されるか3分経過で敗北。1戦は30秒〜3分。
2. **戦利品（ローグライト）**：勝利ごとに「新カード／カード強化／遺物」から1つ選ぶ。
3. **強化シーン**：魂貨でカードのレベルと玉座（魂力回復・上限・耐久・魂貨倍率）を強化。デッキは最大6枚。
4. **転生**：行き詰まったらステージ・カード・強化・遺物を捨てて冥核を得る（今周の最高ステージ6以上で解放）。冥核で「冥王の遺志」（永続強化）を取得。

## 操作

- カードをクリック／タップ、またはキー `1`〜`6` で召喚
- `Space` / `Q`：冥王の裁き（全敵へ範囲攻撃、チャージ制）
- ×1 / ×2：戦闘速度の切り替え
